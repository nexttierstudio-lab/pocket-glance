Pocket Glance

プライバシーポリシー

Pocket Glance が端末に保存するもの、アプリの改善のために送信する限られたデータ、そしてあなたが選べることについて。

NextTier Studio の Pocket Glance · 2026年11月22日施行

{{tr_note}}

01Pocket Glance について

Pocket Glance は Android 向けの個人用家計簿アプリで、個人開発者の公開名である NextTier Studio（以下「当方」）が開発しています。このポリシーはアプリとこのウェブサイトの両方に適用されます。

02端末に保存されるデータ

取引、金額、メモ、カテゴリ、予算、貯金目標、サブスクリプション、リマインダー、設定など、入力した内容はすべてお使いのスマートフォンに保存されます。Pocket Glance にはアカウントも、このデータを受け取るサーバーもないため、当方がそれを見ることはできません。

03収集するデータ

設定 → プライバシーとセキュリティ → 利用状況とクラッシュデータを共有 がオンの間（初期設定はオン）、アプリは Firebase を通じて次の情報を当方に送信します。

  • 利用状況データ（Firebase Analytics）：開いた画面、アプリ内購入があったかどうか。
  • クラッシュデータ（Firebase Crashlytics）：クラッシュやエラーのレポート、起動時間などのパフォーマンス測定値。
  • 端末情報：端末のモデル、Android のバージョン、アプリのバージョン、言語、おおよその国や地域。
  • 識別子：Firebase が作成するインストール ID と、データ送信時に Google が受け取る IP アドレス。

これらのデータは、不具合の修正とアプリの改善にのみ使用します。アプリは、金額、取引、メモなど入力した内容を含まないように設計されています。広告 ID は収集せず、このデータを広告に使うことはありません。Google はアナリティクスデータを 2 か月後に、クラッシュデータを 90 日以内に削除します。

このウェブサイト。あなたが アクセス解析を許可 を選ばない限り、このサイトは Cookie を設定せず、トラッキングも読み込みません。許可した場合、Google Analytics for Firebase と Firebase Performance Monitoring が、閲覧したページ、クリックしたリンクやボタン、スクロールした位置、ページの読み込み速度、ブラウザと端末の種類、言語、おおよその位置情報を記録し、ファーストパーティ Cookie を設定します。拒否する を選んだ場合や、ブラウザが Global Privacy Control 信号を送信している場合は、何も読み込まれません。テーマ・言語・アクセス解析の選択は、お使いのブラウザにのみ保存されます。

04第三者サービス

関わる第三者は Google のみです。

  • Firebase：上記のアプリとウェブサイトのデータを当方に代わって処理します。
  • Google ドライブ：バックアップをオンにした場合、あなた自身の Google アカウントにバックアップを保存します。
  • Google Play Billing：Pro の購入を処理します。カードや銀行の情報を当方が受け取ることはありません。返金やサポートのために、注文記録（注文番号、商品、価格、国など）を確認できます。

Google は米国やその他の国でデータを処理する場合があります。Google のプライバシー ポリシーと Firebase のプライバシー情報をご覧ください。Pocket Glance による Google API から受け取った情報の使用は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠しています。ドライブへのアクセスはバックアップと復元にのみ使用します。

当方はデータを販売せず、広告を表示せず、広告目的でデータを共有しません。法律で求められた場合は、当方が保有する限られたデータを開示することがあります。

05バックアップとデータの削除

Google ドライブへのバックアップは任意です。オンにすると、Pocket Glance だけが使えるドライブ内の非公開アプリフォルダにバックアップを保存し、最新の 5 件を保持します。バックアップはパスワードで保護でき、そのパスワードは端末に保存され、当方は復元できません。スマートフォンの設定でバックアップがオンの場合、Android が端末のバックアップにアプリのデータを含めることもあります。

スマートフォン上のアプリのデータとドライブのバックアップは、いつでも削除できます。手順はヘルプとサポート：データの削除をご覧ください。

06プライバシーの選択

  • 利用状況とクラッシュデータ：設定 → プライバシーとセキュリティ でオフにできます。収集はすぐに止まり、未送信のクラッシュレポートは削除されます。
  • バックアップ：Google ドライブへのバックアップのオン・オフやバックアップの削除は、いつでもできます。
  • このウェブサイト：各ページ下部の アクセス解析の設定 から選択を変更できます。同意を取り消すと、関連する Cookie と ID も削除されます。

お住まいの地域（EEA、英国、カリフォルニア州、インドなど）によっては、個人データへのアクセス・訂正・削除、処理への異議、データ保護当局への苦情申し立ての権利がある場合があります。アプリの利用状況とクラッシュデータは信頼できるアプリを提供するという当方の正当な利益に基づき、ウェブサイトのアクセス解析はあなたの同意に基づいて処理します。アプリのデータは名前ではなくインストール ID に紐づくため、あなたの記録を特定できない場合がありますが、メールをいただければできる限り対応します。

Pocket Glance は成人向けで、子どもを対象としていません。このポリシーは更新されることがあり、最新版と施行日は常にこのページに掲載します。
